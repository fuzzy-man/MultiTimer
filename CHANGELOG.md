## [1.1.0] - 2026-07-08

### Added

- Додано налаштування порогу жовтого попередження в хвилинах.
- Додано жовтий стан favicon, коли хоча б один активний таймер увійшов у попереджувальний інтервал.
- Додано desktop-сповіщення браузера для завершених таймерів.
- Додано кнопку `Видалити` в діалог редагування таймера.
- Додано бейдж версії у верхню частину інтерфейсу.
- Додано паузу й продовження для будильників у режимі `Цільовий час`.

### Changed

- Версію програми підвищено з `1.0.0` до `1.1.0`.
- Типове значення жовтого попередження змінено з `15` на `5` хвилин.
- Поле `Жовті, хв` перейменовано на `Попередження, хв`.
- Кнопка `Наступний день` для будильника тепер показується тільки після завершення.
- Кнопка `Редагувати` для завершеного будильника відкриває діалог із найближчою майбутньою хвилиною.
- Початковий час нового будильника тепер не може одразу потрапити в минуле через секунди поточної хвилини.
- Пауза тепер ставить прочерк у полі `Ціль`, зупиняє хід відліку й не змінює поле `Задано`.
- Продовження будильника перевіряє задану ціль: якщо вона ще майбутня, відлік іде до неї, а якщо вона вже минула, будильник переноситься на наступний день.

### Documentation

- Додано `CHANGELOG.md`.
- Додано `CONTEXT.md` з підсумком змін, зроблених у межах чату.
- Додано в README коротку інформацію про початкову версію, журнал змін і контекст розробки.
- Оновлено README і контекст розробки для нової поведінки паузи.

## [1.0.0] - 2026-06-15

### Added

- Браузерний мульти таймер на HTML, CSS і JavaScript.
- Підтримка багатьох таймерів у вертикальному списку.
- Два режими таймера: тривалість у форматі `години:хвилини` та будильник на конкретну дату й час.
- Збереження стану в `localStorage` з відновленням після повторного відкриття браузера.
- Редагування назв і параметрів таймерів.
- Пауза, продовження, скидання, деактивація, видалення окремих таймерів і очищення всіх таймерів.
- Автосортування, ручне сортування та підтримка `Starred` таймерів.
- Звуковий сигнал через Web Audio API з вибором рингтона, гучності, тривалості сигналу та режимом `Mute`.
- Індикатор стану через favicon і заголовок вкладки.
- Українська й англійська локалізація.
- Темна macOS/glass-подібна тема.

### Changed

- Дати для цільового часу показуються у форматі `yyyy-mm-dd`.
- Тривалість виду `0:90` нормалізується як `1:30`.

### Notes

- Версія `1.0.0` використовується як початковий публічний реліз для поточного стану проєкту.
