# Changelog

Усі помітні зміни в цьому проєкті варто документувати в цьому файлі.

Формат наближений до [Keep a Changelog](https://keepachangelog.com/uk/1.1.0/), а версіонування пропонується вести за [Semantic Versioning](https://semver.org/lang/uk/).

## [Unreleased]

### Fixed

- `Mute` зупиняє вже запланований звук; гучність змінюється під час сигналу. Деактивація, пауза, видалення чи перезапуск таймера припиняють його поточний сигнал, не вимикаючи незалежні сигнали інших таймерів.
- Повторний `Тест` замінює попереднє прослуховування. Аудіовузли звільняються після завершення, а недоступність аудіопристрою не зриває обробку таймерів.
- Автосортування оновлює порядок під час відліку поряд із таймерами на паузі, зберігаючи фокус і виділення тексту. Будильники на паузі сортуються за показаним залишком.
- Після зміни обраного й параметрів зберігається остаточний порядок. Маркер перетягування враховує межу секції обраного.
- Резервний планувальник без worker не додає дві секунди затримки. Секундне оновлення також виявляє прострочення після зміни системного часу.
- Сповіщення worker і сторінки використовують спільний тег для конкретного завершення, без повторного сигналу при заміні повідомлення; новий запуск має окремий тег.
- Відновлення обробляє некоректні часові мітки й дублікати ID; відсутні поля дати та часу відновлюються зі збереженої цілі.
- Зворотний відлік не показує нуль за частку секунди до завершення.
- Виправлено обчислення найближчої хвилини під час переходу на зимовий час і перенесення давнього будильника через сезонне переведення годинника. Неіснуючий локальний час відхиляється у формі.
- Виправлено ISO-роки до 0100, перевірку крайньої дати й положення курсора при редагуванні дати всередині поля.
- Верхню панель ущільнено; виправлено обрізання діалогу й довгих значень на вузькому екрані.

### Changed

- Прибрано невикористані функції сортування й форматування, зайві прапорці, переклади та дублікати CSS.

### Tests

- Розширено набір до 37 регресійних тестів, зокрема для аудіо, worker, сповіщень, дат, сортування та відновлення стану.
- Додано Playwright-перевірку через `file://`: UA/EN, шість розмірів екрана від 320 до 1440 px, діалоги, фокус, перетягування, редагування дати, перезавантаження й сезонні зміни часу для Europe/Kyiv.

## [1.2.1] - 2026-08-31

### Fixed

- Поля назв прив'язано до сталих ID таймерів і вимкнено їх автоматичне заповнення браузером, щоб відновлення сесії після зміни порядку рядків не підміняло назви.
- Подія `input` без `inputType`, яку Firefox надсилає під час відновлення полів, більше не записується як перейменування таймера. Після `pageshow` назви й панель керування повторно відображають стан застосунку.

### Added

- Додано регресійні тести збереження обраного, порядку, станів відліку й паузи, захисту від підміни назв і звичайного редагування.

### Changed

- Версію програми підвищено з `1.2.0` до `1.2.1`.

## [1.2.0] - 2026-08-18

### Added

- Додано фоновий дедлайн-планувальник через inline Web Worker для надійнішого завершення таймерів у неактивній вкладці Firefox.
- Додано резервний одноразовий timeout і негайну перевірку після повернення вкладки у видимий стан.

### Changed

- Версію програми підвищено з `1.1.0` до `1.2.0`.
- Верхній блок застосунку й панель налаштувань тепер залишаються доступними під час прокручування.
- Секундний інтервал використовується тільки для оновлення відображення, а не як єдиний механізм завершення таймера.

### Documentation

- Описано обмеження фонових таймерів при повному вивантаженні вкладки або сні операційної системи.

## [1.1.0] - 2026-07-08

### Added

- Додано налаштування порогу жовтого попередження в хвилинах.
- Додано жовтий стан favicon, коли хоча б один активний таймер увійшов у попереджувальний інтервал.
- Додано desktop-сповіщення браузера для завершених таймерів.
- Додано кнопку `Видалити` в діалог редагування таймера.
- Додано бейдж версії у верхню частину інтерфейсу.
- Додано паузу й продовження для будильників у режимі `Цільовий час`.

### Changed

- Версію програми підвищено з `1.0.0` до `1.1.0`.
- Типове значення жовтого попередження змінено з `15` на `5` хвилин.
- Поле `Жовті, хв` перейменовано на `Попередження, хв`.
- Кнопка `Наступний день` для будильника тепер показується тільки після завершення.
- Кнопка `Редагувати` для завершеного будильника відкриває діалог із найближчою майбутньою хвилиною.
- Початковий час нового будильника тепер не може одразу потрапити в минуле через секунди поточної хвилини.
- Пауза тепер ставить прочерк у полі `Ціль`, зупиняє хід відліку й не змінює поле `Задано`.
- Продовження будильника перевіряє задану ціль: якщо вона ще майбутня, відлік іде до неї, а якщо вона вже минула, будильник переноситься на наступний день.

### Documentation

- Додано `CHANGELOG.md`.
- Додано `CONTEXT.md` з підсумком змін, зроблених у межах чату.
- Додано в README коротку інформацію про початкову версію, журнал змін і контекст розробки.
- Оновлено README і контекст розробки для нової поведінки паузи.

## [1.0.0] - 2026-06-15

### Added

- Браузерний мульти таймер на HTML, CSS і JavaScript.
- Підтримка багатьох таймерів у вертикальному списку.
- Два режими таймера: тривалість у форматі `години:хвилини` та будильник на конкретну дату й час.
- Збереження стану в `localStorage` з відновленням після повторного відкриття браузера.
- Редагування назв і параметрів таймерів.
- Пауза, продовження, скидання, деактивація, видалення окремих таймерів і очищення всіх таймерів.
- Автосортування, ручне сортування та підтримка `Starred` таймерів.
- Звуковий сигнал через Web Audio API з вибором рингтона, гучності, тривалості сигналу та режимом `Mute`.
- Індикатор стану через favicon і заголовок вкладки.
- Українська й англійська локалізація.
- Темна macOS/glass-подібна тема.

### Changed

- Дати для цільового часу показуються у форматі `yyyy-mm-dd`.
- Тривалість виду `0:90` нормалізується як `1:30`.

### Notes

- Версія `1.0.0` використовується як початковий публічний реліз для поточного стану проєкту.
