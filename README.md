# MultiTimer

Браузерний мульти таймер на `HTML`, `CSS` і `JavaScript`.

## Версія

Офіційний релізний тег ще не створений. Поточна версія додатка: `1.1.0`.

## Запуск

Відкрийте `index.html` у браузері.

## Збереження

Додаток використовує `localStorage`. Дані зберігаються локально у конкретному браузері та профілі користувача, тому після закриття й повторного відкриття браузера таймери відновляться.

Зберігаються:

- назва таймера;
- абсолютний час завершення `targetAt`;
- залишок часу для зупиненого таймера;
- режим задання часу: кількість хвилин або цільовий час;
- значення, яке було задано;
- стан деактивації;
- позначка `Starred`;
- налаштування сортування;
- вибрана мова інтерфейсу;
- гучність, рингтон і тривалість сигналу.

Для будильника зберігається конкретна дата і час завершення.

## Функціонал

- Горизонтальні таймери в одному вертикальному списку.
- Темна тема з glass/macOS-подібним стилем.
- Автосортування або ручне сортування кнопкою `Сортувати`.
- При вимкненому автосортуванні таймери можна перетягувати вручну за лівий тримач.
- Напрям сортування: менші значення зверху або більші значення зверху.
- Деактивовані таймери залишаються на своїх місцях під час сортування.
- `Starred` таймери піднімаються вище звичайних і відображаються в окремій секції.
- Перемикач локалізації `UA` / `EN`; вибрана мова зберігається між запусками.
- Версія додатка показується у верхній частині поруч із назвою `MultiTimer`.
- Редагування назви без зупинки таймера.
- Редагування часу через діалог `Редагувати`.
- Видалення таймера доступне також із діалогу редагування.
- Задання тривалості у форматі `години:хвилини` або локальним цільовим часом.
- Для хвилинного таймера тривалість зберігається як загальна кількість хвилин, але вводиться й показується як `4:00`, `0:25`, `26:30`; якщо ввести `0:90`, додаток сам нормалізує це як `1:30`.
- Цільовий час вводиться окремими полями годин і хвилин у 24-годинному форматі, наприклад `18:00`.
- Для будильника можна вибрати дату календарем.
- Для завершеного будильника з'являється кнопка `Наступний день`.
- Для завершеного будильника кнопка `Редагувати` відкриває діалог із найближчою майбутньою хвилиною.
- Відображення залишку, цілі та заданого значення.
- Якщо відлік переходить через добу, показуються дні.
- Можна налаштувати, за скільки хвилин до завершення відлік і ціль підсвічуються жовтим; типово це `5` хвилин.
- Після завершення таймер рахує час понад нуль і показує його червоним.
- Кнопка `Деактивувати` вимикає сигнал і favicon-індикатор для конкретного таймера, але відлік продовжується.
- Деактивовані таймери можна зупиняти й продовжувати так само, як активовані.
- Деактивований хвилинний таймер можна зупинити навіть після завершення, щоб зафіксувати показаний `+час`.
- Для режимів `Хвилини` й `Цільовий час` є кнопка `Зупинити` / `Продовжити`.
- Зупинений таймер зберігає показаний залишок часу, ставить прочерк у полі `Ціль` і не змінює поле `Задано`.
- Для хвилинного таймера після продовження нова ціль обчислюється за збереженим залишком часу.
- Для будильника після продовження відлік іде до заданої цілі, якщо вона ще майбутня; якщо задана ціль уже минула, будильник переноситься на наступний день.
- Для режиму `Хвилини` є кнопка `Скинути`; для режиму `Цільовий час` вона прихована.
- Звуковий сигнал через Web Audio API з регулюванням гучності та режимом `Mute`.
- Можна вибрати рингтон і тривалість сигналу.
- Можна увімкнути desktop-сповіщення браузера, щоб Windows показувала повідомлення, коли час таймера вийшов.
- Індикатор у заголовку сторінки та favicon для активного, жовтого попереджувального й завершеного станів.
- Якщо всі завершені таймери деактивовані, favicon повертається до нормального стану.
- Якщо немає жодного активного таймера, favicon стає нейтральним.
- Видалення окремого таймера і очищення всіх таймерів з підтвердженням.
